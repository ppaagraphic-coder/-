# ควบคุมรับส่งผ้า Meedao

เว็บแอปไฟล์เดียว (`index.html`) สำหรับกรอกใบรับผ้าและใบส่งผ้าของ inchantree meedao ใช้ได้บนมือถือ Android และ iOS

## ความสามารถ

- 2 แบบฟอร์ม: รายการรับผ้า และรายการส่งผ้า (19 รายการ จำนวนแยกชั้น 1–5)
- กรอกข้อมูลหัวฟอร์ม จำนวน และหมายเหตุ ระบบรวมยอดให้อัตโนมัติ
- เซ็นชื่อด้วยนิ้วบนหน้าจอ พร้อมบันทึกวันเวลาที่เซ็น
- บันทึกเป็น PNG หรือ PDF (A4 แนวนอน) และแชร์ PDF ผ่านหน้าต่างแชร์ของมือถือ
- คัดลอกข้อความสรุปไปส่งต่อทางไลน์
- บันทึกข้อมูลอัตโนมัติในเบราว์เซอร์ของเครื่องที่ใช้ (localStorage)

## วิธี deploy ด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub (เช่น `meedao-laundry`)
2. อัปโหลดไฟล์ `index.html` และ `README.md` ไปที่ root ของ repository
   - หรือใช้คำสั่ง
     ```bash
     git init
     git add index.html README.md
     git commit -m "Add laundry forms"
     git branch -M main
     git remote add origin https://github.com/<ชื่อผู้ใช้>/meedao-laundry.git
     git push -u origin main
     ```
3. ไปที่ **Settings → Pages**
4. ที่ **Build and deployment** เลือก **Source: Deploy from a branch**
5. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
6. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/meedao-laundry/`

> ถ้าเป็น repository แบบ private ต้องใช้แพ็กเกจ GitHub ที่รองรับ Pages แบบ private หรือเปลี่ยนเป็น public

## การใช้งานบนมือถือ

- เปิดลิงก์ในเบราว์เซอร์ แล้วเพิ่มลงหน้าจอโฮม
  - iPhone: Safari → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
  - Android: Chrome → เมนู ⋮ → **เพิ่มไปยังหน้าจอหลัก**
- ปุ่ม **แชร์ PDF** จะแสดงเมื่อเบราว์เซอร์รองรับการแชร์ไฟล์ (มือถือส่วนใหญ่)

## ข้อควรรู้

- ข้อมูลที่กรอกและลายเซ็นเก็บในเครื่องและเบราว์เซอร์นั้นเท่านั้น เปิดจากเครื่องอื่นจะไม่เห็นข้อมูลเดิม ล้างข้อมูลเบราว์เซอร์แล้วข้อมูลจะหาย ควรบันทึกเป็น PDF เก็บไว้ทุกครั้งที่เซ็นเสร็จ
- ฟอนต์ IBM Plex Sans Thai โหลดจาก Google Fonts ครั้งแรกต้องมีอินเทอร์เน็ต หากโหลดไม่ได้จะใช้ฟอนต์ไทยของเครื่องแทน
- ต้องเปิดผ่าน HTTPS (GitHub Pages เป็น HTTPS อยู่แล้ว) การแชร์ไฟล์จึงจะทำงาน
